Voidstrap replaces the normal Roblox launcher. Every time you start Roblox, Voidstrap installs or updates it, applies your FastFlags and mods, launches the game, and then stays in the background for in game features like overlays and Discord activity.

## Where things live

The sidebar groups every setting by topic. You can rename, reorder, hide or change the icon of any page from **Appearance**, but **Home** and **Appearance** always stay visible.

| Page | What it covers | Guide |

| Home | Recent games, quick launch, news | [Library and accounts](/features/library/) |
| Integrations | Discord, activity tracking, notifications, Snap Tap, audio | [Integrations](/features/integrations/) |
| Deployment | Roblox channel, updates, downloads, install folder | [Launching and updates](/features/launching/) |
| Appearance | App theme, background, launcher style, language | [Appearance](/features/appearance/) |

## Platform support

Most features work on every desktop platform. Some depend on Windows APIs and are hidden elsewhere, so a missing option usually means it does not apply to your system. See [Linux](/platforms/linux/) and [macOS](/platforms/macos/).

## When changes apply

- App settings save as you change them.
- FastFlags, mods and Roblox settings apply on the next Roblox launch.
- If Roblox is already open, close every Roblox window first.
