Voidstrap draws overlays on top of Roblox while you play. They never touch the game itself, they just sit on top like a very polite sticker.

## Session dock and Overlay Studio

The session dock holds your in game panels. **Overlay Studio** lets you drag each overlay where you want it, resize it and pick what it shows.

## Server readout

Shows the server's location, ping and uptime. The location comes from [ipinfo.io](https://ipinfo.io) when **Server location** is on in **Integrations**.

## Crosshair

A custom crosshair drawn above Roblox. Pick its shape, size and colour, and set a **Crosshair shortcut** key to show or hide it while you play.

## Keystrokes

Shows your keyboard and mouse inputs on screen, with optional sound effects. Themes are fully customisable in the **Keystrokes Theme Editor**, which uses HTML and CSS. Great for videos, or for proving you really did press jump.

## Visual filters

- **Frame generation** and **motion blur** for smoother motion.
- **Colour blind filters** for protanopia, deuteranopia and tritanopia.

## Notifications

Pop ups for server joins, server location, updates and screenshots you take in game.

## Linux

Overlays work on Linux with Sober. Some need **Run Roblox through XWayland** on Wayland sessions, and the app shows a notice when that applies. See [Linux](/platforms/linux/).
