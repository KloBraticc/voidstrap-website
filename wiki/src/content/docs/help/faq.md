## Can Voidstrap get me banned?

Voidstrap does not inject cheats, exploit Roblox, or bypass its security. It manages launching and configuration.

## Is Voidstrap a virus?

Voidstrap is open source, so anyone can [review the code](https://github.com/KloBraticc/Voidstrap).

Security software can flag unsigned or new apps, but don't assume every warning is a false positive. Download from the [official releases](https://github.com/KloBraticc/Voidstrap/releases/latest) and check the file's source before running it.

## Is Voidstrap an exploit?

No, and it never will be.

## Can I run several Roblox windows at once?

No. Multi-instance launching was removed in version `1.1.2.3` and won't come back.

## Which systems are supported?

Windows 10 and newer, Linux, macOS and Android.

## Where are the Windows logs?

Normally in `%LOCALAPPDATA%\Voidstrap\Logs`. If you chose another install folder, use the app's log folder shortcut.

## Where can I get help?

Ask in the [Discord server](https://discord.gg/5tJBqBH8ck), or [report a bug](/help/report-bug/) if something is broken.
