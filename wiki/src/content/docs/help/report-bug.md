## Report a bug

1. Search the [existing issues](https://github.com/KloBraticc/Voidstrap/issues), including closed ones.
2. Check the bug still happens in the [latest release](https://github.com/KloBraticc/Voidstrap/releases/latest).
3. Choose **Bug report** on the [issue forms](https://github.com/KloBraticc/Voidstrap/issues/new/choose).

Describe one problem per report, and include:

- Your Voidstrap version and operating system
- The steps that cause the problem
- What you expected, and what actually happened
- A log, screenshot or recording, if you have one

| System | Also include |
| --- | --- |
| Linux | Distribution, package format, desktop session, Roblox runtime |
| macOS | macOS version, Intel or Apple silicon |
| Android | App flavor (`play` or `direct`), and Shizuku, ADB or root |

:::danger[Remove private information]
Take passwords, login cookies, access tokens and private server links out of logs and screenshots before posting.
:::

## Suggest a feature

Choose **Feature request** on the [issue forms](https://github.com/KloBraticc/Voidstrap/issues/new/choose). Explain the problem, who it affects, and what you'd like to happen.

Features for cheating, exploiting, account theft or bypassing Roblox's security are not accepted.

## Report a security problem

**Don't post it publicly.** Report it privately in either of these ways:

- [Open a private advisory](https://github.com/KloBraticc/Voidstrap/security/advisories/new) on GitHub
- Message a staff member on the [Discord server](https://discord.gg/5tJBqBH8ck)

Include the affected app, version and platform, what an attacker could do, and how to reproduce it. Keep the details private until a fix is released. Only the latest release gets security fixes.

Problems in Roblox itself go to the [Roblox bug bounty program](https://hackerone.com/roblox).
