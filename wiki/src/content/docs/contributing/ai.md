---
title: Using AI tools
description: The rules for contributing with AI help.
---

AI is allowed in Voidstrap, including for new contributors. You're still responsible for what you submit.

## Before you change anything

- Read the README and contributing guide.
- Follow the code you plan to change from start to finish.
- Check how it works on each platform your change affects.
- Check AI explanations against the actual code.

## Before you send it

- Read the whole diff, including anything AI wrote.
- Build and test it.
- Be ready to explain what changed, why, and how you tested it.

The same review and checks apply to everyone. Coding assistants should follow [AGENTS.md](https://github.com/KloBraticc/Voidstrap/blob/main/AGENTS.md).
