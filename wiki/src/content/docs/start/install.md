---
title: Install Voidstrap
description: Install Voidstrap on Windows, Linux or macOS.
---

Voidstrap runs on Windows 10 and newer, Linux, macOS and Android. Pick your system below.

## Windows

Open PowerShell and run:

```powershell
irm https://voidstrapp.pages.dev/quick-install | iex
```

Or do it by hand:

1. Download the [latest release](https://github.com/KloBraticc/Voidstrap/releases/latest).
2. Run the `.exe` and finish the setup.
3. Open Voidstrap.

## Linux and macOS

Open a terminal and run:

```bash
curl -fsSL https://voidstrapp.pages.dev/install.sh | sh
```

On Linux, Voidstrap runs Roblox through [Sober](https://sober.vinegarhq.org) and Studio through [Vinegar](https://github.com/vinegarhq/vinegar).

Using Gentoo or NixOS? See [Gentoo and NixOS](/start/linux-distros/).

## Android

See [Android setup](/start/android/). It needs one extra permission step.

:::caution[Only use official downloads]
Get Voidstrap from the [official releases](https://github.com/KloBraticc/Voidstrap/releases/latest), and check where a file came from before running it.
:::
