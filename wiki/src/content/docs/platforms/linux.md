title: Linux
description: How Voidstrap runs Roblox on Linux through Sober and Studio through Vinegar.
---

On Linux, Voidstrap runs the Roblox player through **Sober** and Roblox Studio through **Vinegar**. Voidstrap installs and sets them up for you on first launch. See [Linux distros](/start/linux-distros/) for install steps.

## What works

Launching, FastFlags, mods, Discord Rich Presence, activity tracking, the matchmaker, overlays and the equalizer all work. Mods are mapped into Sober's package layout automatically.

## Wayland

Window title, game icon and server info need **Run Roblox through XWayland** on Wayland sessions. The app shows a notice when this applies.

## Hidden on Linux

Windows only features such as the NVIDIA profile and Windows backdrops are hidden, so you never see a switch that does nothing.
